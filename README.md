# Mechanic Shop API

## Setup

```bash
pip install -r requirements.txt
python app.py
```

## Swagger Documentation

Open:

http://127.0.0.1:5000/api/docs

## Run Tests

Run each test module:

```bash
python -m unittest app.tests.test_customers
python -m unittest app.tests.test_mechanics
python -m unittest app.tests.test_service_tickets
```
